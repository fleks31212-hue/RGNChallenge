# RNG Challenge (Fabric 1.21.1)

Мод выдаёт игроку случайное задание раз в минуту. На выполнение даётся 60 секунд.
За успех выдаются алмазы; за провал применяется одно из 20 случайных наказаний.

## Требования
- Minecraft 1.21.1
- Java 21
- Fabric Loader 0.16.9 или новее
- Fabric API для 1.21.1

## Сборка
1. Установи JDK 21.
2. Открой папку проекта в IntelliJ IDEA или терминале.
3. Выполни `gradle build` (при наличии Gradle) или импортируй проект как Gradle-проект.
4. Готовый JAR появится в `build/libs/`.

## Установка
Скопируй `rng-challenge-1.0.0.jar` из `build/libs/` в папку `mods` клиента/сервера Fabric.

## Примечание
Задания проверяют увеличение количества нужного предмета в инвентаре относительно момента выдачи задания.
Логика выполняется на сервере, поэтому поддерживается одиночная игра и мультиплеер.
